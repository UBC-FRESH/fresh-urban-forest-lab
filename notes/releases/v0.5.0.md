# v0.5.0

Status: released. Tag: `v0.5.0`.
Date: 2026-11-14.

## What this is

The P58 walk-mode release. It keeps the v0.4.1 data products and public portal unchanged
and adds first-person navigation to the 3D scene.

## What changed

- Added **Walk** mode to the 3D scene: pointer-lock mouse look, WASD/arrow movement,
  Shift sprint, and terrain-following eye height.
- Added a Walk/Orbit toggle, crosshair, and control hint.
- Walk mode clamps to scene bounds and exits when switching tabs or choosing Orbit.
- Escape releases the mouse but leaves Walk mode active.
- Added explicit Walk-mode controls and limits to the web application guide.
- Corrected the P58 design note and removed a machine-specific deployment path from the
  P58 report.
- Package, citation, and runtime version metadata now agree at `0.5.0`.

## Not changed

- No scientific product, data claim, default layer, or corrected-product threshold changed.
- The corrected change/action/turnover layers remain the UI defaults; original lineages
  remain selectable.
- The public portal routes and demo datasets are unchanged.

## Limits

- Walk mode is in-engine navigation, not Google Street View imagery.
- It does not model building interiors or complete physical collision.
- Terrain height comes from the dataset grid, not survey-grade pedestrian ground.
- No jump, crouch, or physics.
- The four western vertical-control outliers and the P32 review gap remain documented.
