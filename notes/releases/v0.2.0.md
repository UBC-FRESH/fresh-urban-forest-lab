# v0.2.0 release notes (draft)

Status: draft, not tagged. Release actions need maintainer approval.

## Highlights

- Observed-change product for UBC: LidarBC 2016 ↔ UBC 2021, with a Change tab.
- Inventory completeness panel and measured/imputed flags.
- Detection validation and local height-diameter calibration.
- LidarBC and CanElevation tile discovery with manifests and checksum-aware downloads.
- Local OpenCode assistant behind the `+ Ask` pill.
- Terrain-based 3D buildings and reverse-proxy path-prefix support.

## Method caveats

- The observed change is a thresholded CHM comparison, not a calibrated growth rate.
- The 2016 and 2021 acquisitions differ in season and vertical datum.
- Detection validation found over-segmentation; precision is not a clean accuracy estimate
  because the inventory is incomplete.
- Local allometry reduces height RMSE but is not an annual growth calibration.
- City of Vancouver 2018↔2022 change is not included because the tile host blocks
  automated download.
